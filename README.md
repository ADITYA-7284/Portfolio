# Aditya Kumar Thakur — Portfolio

A modern, responsive portfolio website built to showcase my software development projects, creative design work, and full-stack engineering capabilities.

Live Demo: [adxtya-portfolio.netlify.app](https://adxtya-portfolio.netlify.app)

---

## 🚀 Features

* **Interactive Navigation:** Smooth single-page scrolling across sections (Home, Work, Design, Contact).
* **Dynamic Content:** Showcases full-stack applications, competitive programming achievements, and design work.
* **Responsive Layout:** Tailored design that scales seamlessly across desktop, tablet and mobile browsers.
* **Modern UI/UX:** Clean dark-mode aesthetics with custom animations and polished interactive controls.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** React, HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
* **Bundler & Build Tools:** Webpack, Babel
* **Backend / API:** Node.js, Express.js, MongoDB
* **Deployment & Hosting:** Netlify (Frontend), Git / GitHub

---
